# Portable AI Interview Coach

A portable, provider-independent interview practice skill for 15–30-minute sessions. Compatible with Claude, Gemini, ChatGPT and other chat assistants that accept Markdown instructions.

## Getting started
1. Read `SKILL.md` and `references/BOOTSTRAP_ANY_AI.md`.
2. Say **Start 15** or **Start 30** to begin practice. The assistant will not start a quiz automatically.
3. Answer using voice or text. The assistant waits for the explicit word **Finished** before giving feedback.
4. Use **Close session** for a scorecard and updated `references/PROGRESS.json`. Save your updates locally.

## Privacy / personal backups
**This is the public, sanitized edition.** The private historical interview scores, job applications and personal profile are intentionally not committed. The original personal continuity ZIP must be kept separately in a private location. Before using the skill on another platform, import your privately held profile and history as needed. Never publish API keys, CV addresses, private job applications or financial data.

## Key learning framework
DART: **Direct → Actions → Risks/Trade-offs → Test/Decision.**
