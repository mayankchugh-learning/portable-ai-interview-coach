# Public coaching lessons (anonymized)

This file contains general lessons only; prior personal practice scores and identifiable interview outcomes are **not included** in the public repository. Keep your private original historical file as a separate backup.

1. Answer the exact question first, preferably in the first sentence.
2. Follow DART: recommendation → 2–3 actions → important risk/trade-off → objective validation/decision.
3. Identify the failing technical layer instead of listing every possible system component.
4. Enforce authorization before retrieval; authentication is not blanket content permission.
5. A central usage dashboard cannot transfer provider-enforced quotas between isolated applications.
6. Usage/engagement is not the same as demonstrated learning or business impact.
7. Name responsible owners, approval gates and safe alternatives; never bypass mandatory controls.
8. Preserve old attempts when importing private practice history and do not invent scores.
