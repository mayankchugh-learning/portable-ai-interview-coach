# Getting started

1. Open `SKILL.md`.
2. In Claude, Gemini, ChatGPT or another assistant, provide `references/BOOTSTRAP_ANY_AI.md` and relevant reference files.
3. Say **Start 15** or **Start 30**.
4. Only evaluate after you explicitly say **Finished**.
5. Save a new personal `PROGRESS.json` after practice in a **private** location, never in this public repository.
6. Use **Close session** to end; questions must not start automatically.

A separate, optional local learning-assistant project is `coursewise-local-ai-poc`.
